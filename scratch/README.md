# Scratch Directory

Folder `scratch/` digunakan untuk bahan kerja sementara, dokumen administratif, contoh dokumen, catatan bimbingan, panduan kuliah, laporan kerja, cheatsheet, dan draft yang tidak menjadi data penelitian langsung.

## Struktur

- `00-admin-kampus/`: form kampus, surat, dan dokumen administratif.
- `01-panduan-dan-materi-kuliah/`: panduan penulisan, materi metodologi, dan bahan kuliah.
- `02-contoh-dokumen/`: contoh PPT, contoh kerangka, atau contoh format.
- `03-bimbingan/`: catatan bimbingan.
- `04-cheatsheets/`: panduan eksekusi lapangan dan checklist kerja.
- `05-laporan-kerja/`: laporan audit, manifest pemindahan, dan dokumen kerja.
- `06-seminar-proposal/`: bahan pendukung seminar proposal yang bukan data penelitian.
- `07-draft-kerja/`: draft sementara.
- `99-temp/`: file sementara.

Jika file akan dipakai sebagai bukti data skripsi, pindahkan ke `resource/`.
