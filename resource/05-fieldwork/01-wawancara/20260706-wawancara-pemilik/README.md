# Dataset Wawancara Pemilik Nasi Gerilya

Kode sumber utama: `W-PM-20260706`  
Tanggal wawancara: 2026-07-06  
Informan: Richard, pemilik Rumah Makan Nasi Gerilya  
Tujuan: data susulan untuk memperkuat Bab IV, Bab V, triangulasi, IFAS/EFAS, dan SWOT.

## Struktur

- `raw/audio/`: tempat rekaman asli apabila nanti tersedia.
- `raw/photos/`: foto dokumentasi lapangan bersama pemilik usaha.
- `transcripts/`: keterangan status transkrip.
- `notes/`: catatan ringkas wawancara pemilik.
- `manifest/`: manifest sumber dan manifest file.
- `compiled/analysis/`: rekap analitis, koding `TW-PM`, dan dokumentasi foto.

## Isi Pokok

Wawancara memuat komposisi kanal penjualan, sumber dan penyimpanan bahan, kontrol konsistensi rasa, batas pembahasan margin, struktur leader, pengelolaan aplikasi GrabFood, pemasaran KOL, kerja sama APINDO, reputasi halal/Rising Star GrabFood, pengembangan Flowie, kemandirian leader, dan regenerasi wakil leader.

Dokumentasi foto memperlihatkan kebersamaan peneliti dengan pemilik Nasi Gerilya di lokasi usaha saat pengumpulan data lapangan.

## Status Kualitas Data

Data ini berupa catatan ringkas dari hasil wawancara. Data sudah cukup untuk menutup sebagian gap wawancara pemilik utama dan memperkuat tema yang sudah muncul pada wawancara pegawai, intern business consultant, pelanggan, observasi GrabFood, dan dokumentasi kinerja. Untuk kutipan langsung atau angka kinerja rinci, tetap diperlukan konfirmasi lanjutan.
