# Dataset Wawancara Lapangan Nasi Gerilya

Periode sumber: 2026-07-01 sampai 2026-07-04  
Dirapikan: 2026-07-05  
Tujuan: bukti wawancara untuk Bab IV, triangulasi, IFAS/EFAS, dan SWOT skripsi tentang strategi pemasaran Nasi Gerilya pada GrabFood.

## Isi Utama

- `raw/audio/`: audio asli yang relevan, diberi kode sumber stabil.
- `transcripts/`: transkrip siap baca. Banner TurboScribe dibersihkan, tetapi isi wawancara tidak diedit substantif.
- `notes/`: catatan manual wawancara kompetitor.
- `compiled/processed-audio/`: audio gabungan Ririn dalam urutan logis dan daftar sumbernya.
- `compiled/analysis/`: rekap/koding temuan yang bisa dipakai untuk Bab IV dan triangulasi.
- `manifest/`: manifest sumber, manifest file, dan daftar file yang dikeluarkan dari paket final.

## Catatan Kualitas

Transkrip otomatis masih perlu divalidasi manual sebelum dipakai sebagai kutipan langsung dalam skripsi. Untuk analisis tematik, gunakan manifest sumber dan file koding di `compiled/analysis/` agar setiap temuan tetap bisa dilacak ke kode sumber.
