\sectionbar{Panduan Pelaksanaan}
\begin{enumerate}[label=\arabic*.,leftmargin=*,itemsep=1mm]
\item Mulai dengan membangun suasana nyaman dan menjelaskan tujuan penelitian secara singkat.
\item Pastikan informan memang pernah membeli Nasi Gerilya melalui GrabFood.
\item Gunakan pertanyaan utama sebagai panduan. Jika jawaban informan belum jelas, gunakan probing.
\item Catat pengalaman konkret, alasan, contoh kejadian, dan kata-kata khas informan.
\item Hindari pertanyaan yang menggiring, misalnya "Setuju kan rasanya enak?".
\item Akhiri wawancara dengan memberi kesempatan informan menambahkan hal lain.
\end{enumerate}
