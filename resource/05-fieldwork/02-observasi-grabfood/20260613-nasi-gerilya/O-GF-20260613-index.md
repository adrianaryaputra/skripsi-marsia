# Observasi GrabFood Nasi Gerilya - 13 Juni 2026

Dokumen ini merangkum hasil dokumentasi layar GrabFood untuk merchant **Nasi Gerilya - Glugur Kota** pada 13 Juni 2026.

## Lokasi File

- `raw/`: 40 screenshot asli dari folder temp, termasuk 2 file duplikat identik.
- `cropped/`: 38 screenshot unik yang sudah dipangkas status bar ponselnya.
- `compiled/O-GF-20260613-contact-sheet-cropped.jpg`: contact sheet untuk membaca semua screenshot unik secara cepat.
- `compiled/O-GF-20260613-dokumentasi-observasi.pdf`: dokumen PDF 20 halaman berisi screenshot unik yang sudah disusun dua gambar per halaman.
- `O-GF-20260613-manifest.csv`: peta file asli, file raw, file crop, kategori, hash, dan catatan duplikat.
- `coded-data/`: crop granular untuk nama toko, rating, promo, menu, harga, sold out, dan ulasan.
- `O-GF-20260613-coded-manifest.csv`: manifest data terkode yang siap dipakai untuk Bab IV/triangulasi.
- `O-GF-20260613-coded-index.md`: ringkasan bacaan cepat untuk data terkode.
- `compiled/O-GF-20260613-coded-contact-sheet.jpg`: contact sheet semua crop granular.

## Cakupan Data

- Profil toko, rating, ringkasan ulasan, dan informasi layanan GrabFood.
- Tampilan menu, kategori produk, harga, lauk tambahan, minuman, dan menu promo.
- Daftar promo/diskon yang tampil di aplikasi.
- Ulasan pelanggan terbaru, foto ulasan, serta balasan restoran.

## Catatan Kualitas Data

- Screenshot nomor 010 adalah duplikat identik dari nomor 009.
- Screenshot nomor 020 adalah duplikat identik dari nomor 019.
- Versi crop hanya memangkas status bar ponsel; isi halaman GrabFood tetap dipertahankan.
- Data ini dapat dipakai untuk observasi tampilan platform, bukti digital, analisis bauran pemasaran, analisis ulasan pelanggan, triangulasi, dan penyusunan IFAS/EFAS.

## Catatan Analisis Awal

- Bukti profil platform dapat diambil dari screenshot `031`, terutama untuk menunjukkan keberadaan merchant, rating, ringkasan ulasan, dan informasi layanan di GrabFood.
- Bukti produk dan harga dapat diambil dari screenshot `008` sampai `028`, yang menampilkan variasi menu, paket, lauk tambahan, minuman, sambal, side dish, dan menu promo.
- Bukti promosi dapat diambil dari screenshot `029` dan `030`, yang menunjukkan daftar promo/diskon yang tampil pada aplikasi.
- Bukti respons layanan dapat diambil dari screenshot ulasan karena beberapa ulasan memperlihatkan balasan restoran terhadap komentar pelanggan.
- Isu yang dapat dikodekan sebagai kelemahan awal adalah keluhan terkait kelengkapan pesanan, kesesuaian item, dan pengalaman pelanggan.
- Isu yang dapat dikodekan sebagai kekuatan awal adalah variasi menu yang luas, adanya promo, rating toko, dan adanya respons restoran terhadap ulasan pelanggan.
- Data ini sebaiknya ditriangulasi dengan wawancara pemilik/admin GrabFood dan data internal penjualan sebelum dijadikan temuan akhir Bab IV.
