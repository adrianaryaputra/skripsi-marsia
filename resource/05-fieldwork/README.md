# Resource Fieldwork

Folder ini menyimpan data penelitian utama dan bahan metodologis yang dipakai untuk pengumpulan data lapangan.

## Struktur

| Folder | Isi |
|---|---|
| `00-instrumen-penelitian/` | Angket, pedoman wawancara, PDF instrumen, dan sumber LaTeX instrumen. |
| `01-wawancara/` | Audio, transkrip, catatan, dan manifest wawancara lapangan, termasuk dataset pemilik 2026-07-06. |
| `02-observasi-grabfood/` | Observasi visual GrabFood Nasi Gerilya dan kompetitor. |
| `03-rekrutmen-informan/` | Bahan rekrutmen informan. |
| `04-survei-pelanggan/` | Data respons angket pelanggan. |
| `07-rekap-koding/` | Rekap koding temuan lapangan. |
