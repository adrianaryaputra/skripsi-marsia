# Analysis Resource Index

Folder ini menyimpan bahan olahan analisis setelah data lapangan masuk ke `resource/05-fieldwork/`.

## Subfolder

- `triangulation/`: peta hubungan antar sumber data lapangan dan kode temuan.
- `ifas-efas/`: bahan kerja matriks IFAS/EFAS.
- `swot/`: bahan kerja matriks SWOT dan alternatif strategi.
- `gap-closure/`: register gap, protokol klaim sementara, dan checklist data susulan.
- `appendix-reproducibility/`: audit keterlacakan appendix ke bahan resource.
