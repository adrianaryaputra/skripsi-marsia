# Gap Closure Resource

Tanggal susun: 2026-07-05

Folder ini menyimpan aturan kerja untuk menutup keterbatasan bukti lapangan tanpa mengarang data. Dokumen ini dipakai sebelum menulis Bab IV dan Bab V agar analisis tetap dapat diajukan, tetapi klaimnya tidak melebihi kekuatan data yang tersedia.

## Prinsip

1. Gap tidak ditutup dengan data fiktif.
2. Gap ditutup dengan batasan klaim, triangulasi silang, dan catatan keterbatasan.
3. Jika data susulan didapat, data baru harus masuk ke `resource/` lebih dulu, diberi kode, lalu baru dipakai untuk merevisi Bab IV, Bab V, triangulasi, IFAS/EFAS, dan SWOT.
4. Klaim "meningkatkan penjualan" harus ditulis sebagai potensi atau arah strategi, kecuali ada data kinerja yang membuktikan perubahan penjualan.

## File

- `GAP-20260705-gap-register.csv`: daftar 4 gap, risiko analisis, strategi penutupan, dan klaim yang boleh/tidak boleh ditulis.
- `GAP-20260705-provisional-analysis-protocol.md`: aturan penulisan analisis sementara untuk Bab IV dan Bab V.
- `GAP-20260705-future-data-intake-checklist.md`: checklist bila nanti wawancara pemilik, data kinerja, tambahan pelanggan, atau tambahan kompetitor berhasil didapat.

## Status

Analisis dapat dilanjutkan sebagai analisis kualitatif berbasis triangulasi. Namun, beberapa temuan harus diberi batas sebagai "berpotensi", "mengarah pada", atau "menunjukkan indikasi", bukan "terbukti meningkatkan penjualan".
