Tanggal penyusunan: 2026-07-05  
Sumber utama: `PS-20260705-prasurvey-coded-manifest.csv`

## Fungsi Pra-Survei

Pra-survei dipakai untuk tiga fungsi:

1. Memberi konteks awal Bab I dan Bab III.
2. Menyediakan kode awal untuk faktor internal dan eksternal SWOT.
3. Menjadi pembanding historis terhadap data lapangan Juni-Juli 2026.

Pra-survei tidak dipakai untuk menggantikan data lapangan. Jika data lapangan tersedia, data lapangan menjadi dasar utama kesimpulan Bab IV/V.

## Aturan Level Klaim

| Level | Arti | Contoh penggunaan |
|---|---|---|
| `context` | Bukti hanya memberi konteks atau latar. | Profil usaha, foto storefront, daftar kanal. |
| `moderate` | Bukti dapat mendukung analisis jika dikaitkan dengan sumber lain. | Promo berpengaruh, harga sensitif, menu tertentu menarik. |
| `strong-if-triangulated` | Bukti kuat bila disandingkan dengan data lapangan yang sudah ada. | Hero menu, stok, antrean, konsistensi rasa, kompetitor utama. |
| `strong-if-updated` | Bukti kuat jika angka terbaru tersedia atau observasi terbaru dipakai. | Rating, indeks kinerja, data kontribusi GrabFood. |

## Catatan Keterbatasan

Koding prasurvey sudah detail, tetapi bukan pengganti empat data yang belum lengkap. Untuk sidang atau izin lanjut penulisan, data ini cukup membantu menunjukkan bahwa analisis sudah punya dasar dan batas klaim. Untuk revisi final, empat gap tetap perlu dikejar jika waktu memungkinkan.
